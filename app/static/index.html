⚡ Power Automate Workflow Definition Reference

Direct copy-paste WDL expressions, trigger conditions, and schemas for Power Automate deployment.

1. Trigger Condition (Settings > Trigger Conditions on 'When a new email arrives (V3)')
@and(
  greater(length(triggerOutputs()?['body/attachments']), 0),
  or(
    contains(toLower(triggerOutputs()?['body/subject']), 'invoice'),
    contains(toLower(triggerOutputs()?['body/subject']), 'bill'),
    contains(toLower(triggerOutputs()?['body/subject']), 'service request')
  )
)
2. Attachment Format & Signature Filter (Inside 'Apply to each attachment')
@and(
  or(
    endsWith(toLower(items('Apply_to_each_attachment')?['name']), '.pdf'),
    endsWith(toLower(items('Apply_to_each_attachment')?['name']), '.png'),
    endsWith(toLower(items('Apply_to_each_attachment')?['name']), '.jpeg'),
    endsWith(toLower(items('Apply_to_each_attachment')?['name']), '.jpg')
  ),
  greater(items('Apply_to_each_attachment')?['size'], 10240)
)
3. Total Amount Cleaning WDL Expression (Strips symbols, commas, handles nulls)
if(
  empty(outputs('Extract_information_from_invoices')?['body/responsev2/predictionOutput/labels/InvoiceTotal/value']),
  0.0,
  float(
    replace(
      replace(
        replace(
          replace(
            string(outputs('Extract_information_from_invoices')?['body/responsev2/predictionOutput/labels/InvoiceTotal/value']),
            '$', ''
          ),
          '₹', ''
        ),
        '€', ''
      ),
      ',', ''
    )
  )
)
